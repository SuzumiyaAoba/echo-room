昨日のあなたが、明日の道を織る。沈んだ街を進む、ドット絵のアクションローグライトです。移動と射撃の記録を「残響」として呼び、今の自分との間に光糸を張って、敵と弾をほどきます。

## 最初の灯り

ゲームを開いたら「灯りをともす」から出発できます。最初は三つの短い案内が出ます。「灯りの練習をする」を選ぶと、体力を失わず、同じ操作で五つのお題を試せます。練習を終えると元の航路へ戻れます。

<Steps>
  <Step>移動しながら射撃。広い道を歩いて、昨日の軌跡をつくります。</Step>
  <Step>残響を呼ぶ。過去の自分から離れ、間に張る光糸を敵や弾へ重ねます。</Step>
  <Step>残響の場所で光を解放。近くの敵と弾をほどき、出口へ進みます。</Step>
</Steps>

光糸の中ほどに来る弾はほどけます。足元へ来る弾は、歩くか回避でよけましょう。画面下の録画の道と、残響の手持ち・充填の表示を読むと、次の糸を張りやすくなります。

## 手に合う操作で

<Matrix title="標準の操作" cols="キーボードとマウス,標準配置のゲームパッド">

- 移動 | WASD / 矢印キー | 左スティック
- 射撃 | J / Z / マウスの左ボタン | RT / R2
- 照準 | マウス。画面から離すと自動照準 | 右スティック
- 回避 | SPACE / SHIFT | A / ×
- 残響 | Q | RB / R1
- 解放 | R | LB / L1
- 次の航路 | 部屋の奥でE | 部屋の奥でB / ○
- 一時停止 | ESC / 画面のⅡ | START

</Matrix>

タッチでは左側で移動し、右側で照準と射撃。回避・残響・解放は中央のボタンから使えます。縦向きでも遊べ、横向きにすると戦場を大きく映せます。

設定ではキーの割り当て、音楽・効果音、振動・発光、照準補助を調整できます。ゲームパッドのメニューは左スティック・十字キーで選択、A / ×で決定、B / ○で戻る。右スティックで本文を読み、LB / RBで一画面ずつ進めます。

## 一度の旅と、帰る街

三つの地域、24部屋。分岐では戦い方・地形・織片を見比べ、休息や行商を選べます。織片は一つの航路の間、重なり続けます。違う道具や組み合わせで、光糸の張り方も変わります。

倒れても持ち帰った記憶は消えません。工房で道具を解放し、灯した場所や手紙の記憶で街を修復できます。帰還後の「直近の旅」で装備と手応えを振り返り、同じ装備で次の支度へ進めます。

## 記憶を持ち運ぶ

記憶と途中の航路は、このURLのブラウザに保存されます。保存は部屋の区切りで行われ、戦闘の途中で閉じると、その部屋の入口から再開します。

別のブラウザや配信先へ移る時は、設定の「記録を書き出す」でJSONファイルを残してください。移動先の灯台画面で設定を開き、「記録を取り込む」から内容を確認して移せます。直前の取り込みを戻すこともできます。

URL、ポート、ブラウザのプロフィールを替えると、保存先も変わります。見つからない記録は、もとのURLとプロフィールを確認してください。プライベートな閲覧や、ブラウザのデータ削除で消えることがあるため、大切な帰還の記録は書き出して残せます。

## このパッケージから起動する

配布ZIPをフォルダーごと展開してください。Node.js 18以降がある環境なら、追加のパッケージを入れずに起動できます。展開したフォルダーで次を実行します。

```console
node start.mjs
```

ブラウザで [灯台を開く](http://127.0.0.1:4173/) と遊べます。終了はターミナルでCtrl+C。次も同じURLを使うと、記録が残ります。4173がほかで使われている時は、そのゲームを終了するか、次のように別のポートを指定します。

```console
node start.mjs --port 4174
```

その場合は表示されたURLを開いてください。ポートを替えると保存先も変わるため、必要な記録は書き出して移せます。この手引きはHTMLファイルなので、そのまま開いて読めます。ゲーム本体は上の起動補助かWeb配信で開いてください。

Webで配信する場合は、`web/` 内の全ファイルと `assets/` フォルダーを同じ場所へ置きます。ルートでもサブディレクトリでも配信できます。HTTPSまたはlocalhostで一度読み込みが完了すると、Service Workerがゲームと使用ソフトウェアの表記を保存し、通信を切った時も開けます。

`BUILD.json` は本体と案内、起動補助の版番号・資源ごとのSHA-256を記録しています。ゲームの保存データは配布物に含めていません。
